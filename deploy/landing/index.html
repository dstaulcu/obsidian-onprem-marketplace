Plugin marketplace

Approved Obsidian plugins, installed with the On-Prem Marketplace plugin in Obsidian.

Nominate a plugin

Plugins are installed from inside Obsidian by the On-Prem Marketplace plugin. If you don't have it yet, set it up once with the om tool (Windows).

  1. Download om.exe and save it in a folder you can write to and run programs from. Your Downloads folder is fine unless your computer blocks programs there. It needs no installation.

      Compare the SHA-256 after downloading (ask an admin for it by another route if you want to be sure).

      The download is not published yet. Ask the marketplace admins for om.exe.

    • Open PowerShell in the folder with om.exe. In File Explorer, open that folder, click the address bar, type powershell and press Enter. Then run these three commands. Replace My Vault with the name om vaults shows for your vault. 
      .\om.exe vaults
.\om.exe init --registry  --vault "My Vault"
.\om.exe marketplace
      The second command saves the address and the marketplace's public key (the key your computer uses to check that an approval is genuine) and prints the key's fingerprint. If you want to be certain it is the right key, compare the fingerprint with one your admins give you. Where to find it
    • In Obsidian, open Settings, then Community plugins, turn off Restricted mode, and enable On-Prem Marketplace. Click the store icon in the left ribbon (or run the command Browse internal plugins) to install, update or review plugins from now on.

    Already have the On-Prem Marketplace plugin? Just open it from the ribbon. om.exe is for Windows; on another system ask your admins for the setup script. Something not working? Ask the marketplace admins.
