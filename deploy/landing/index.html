Plugin registry

This is a read-only registry of approved Obsidian plugins. It is meant to be used by the om command and the On-Prem Marketplace plugin, not browsed by hand.

For clients

Point om or the plugin at this address. The registry files are:

  • index.json: the latest version of each plugin
  • /plugins/<id>/versions.json: every version, with hashes

Nothing here can change anything. Approvals are signed separately and checked by the client.
